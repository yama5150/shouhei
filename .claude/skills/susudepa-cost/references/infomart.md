# インフォマート マイカタログCSV の扱い

## ファイルの特徴

- 文字コードは **cp932**（Shift_JIS）。utf-8で開くと失敗する。
- 改行が CRLF + NEL 混在。`csv.reader` に `io.StringIO` を通せば読める。
- 1行目はタイトル行、**2行目がヘッダ**。データは3行目から。
- 2026/09時点で 2,537品目、うち単価が入っているのは 2,274品目。

## 主要な列（0始まりのインデックス）

| index | 内容 |
|---|---|
| 8 | 食品大分類 |
| 9 | 食品中分類 |
| 10 | 食品小分類 |
| 11 | 商品コード |
| 12 | 商品名 |
| 13 | 規格 |
| 14 | 入数 |
| 16 | 単位 |
| 17 | 単価（税抜） |
| 23 | 取引先名 |

## 円/kg への換算

1. 単位が `kg` なら単価がそのまま円/kg。
2. そうでなければ **規格 → 商品名** の順に内容量を探す。
3. どちらからも読めなければ未換算のまま残す。埋めない。

換算できるのは概ね **全体の7割**。残り3割は規格欄が空で内容量が判断できないもの。
使う品目だけ手で内容量を入れれば足りる。全件を埋めようとしない。

### 正規表現の目安

```python
W_RE  = re.compile(r'(\d+(?:\.\d+)?)\s*(kg|g|グラム|キロ)(?![a-zA-Z])', re.I)
V_RE  = re.compile(r'(\d+(?:\.\d+)?)\s*(ml|cc|リットル|ℓ)', re.I)
VL_RE = re.compile(r'(\d+\.\d+)\s*L(?![a-zA-Z])')   # 1.8L のみ。2L等級を除外
MULT  = re.compile(r'[×xX*]\s*(\d+(?:\.\d+)?)')
```

- 文字列は先に `unicodedata.normalize('NFKC', s)` で全角を潰す。
- `MULT` の乗算は **単位が C/S・箱・ケース・函 のときだけ**適用する。
  単位が「本」「個」「枚」なら、規格の `40g×50本` はケース仕様の記述であって、
  単価は1本の値段。掛けると10倍以上ずれる。
- 換算元（規格 / 商品名 / 単位kg）を列として残す。商品名由来は目視確認の対象。

## 出力

xlsxの `単価マスター` シートに全件を入れ、オートフィルタと `C2` 固定を掛ける。
`原価計算` シートから `INDEX + MATCH` で引く。手入力列を用意し、そちらを優先させる。
