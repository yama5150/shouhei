# 標準レシピ書の書式

## 基本方針

**A4一枚に収める。** 厨房に貼る・新人に渡す用途なので、めくらせない。
入らない場合は節を統合する（「下味」と「衣」を「配合」にまとめる等）。文字は削らない。

## 構成

```
標準レシピ・原価表          ← 小さいラベル
<料理名>                    ← 大きく
<仕込み単位> ／ <仕上がり重量> ／ <個数>   ← サブタイトル、下にアクセント罫

1. 原価内訳
   表：材料 / 仕入単価 / 使用量 / 原価
   合計行はグレー地・太字
   下にサマリーの帯：1回仕込み / 1個あたり / 100gあたり
   注記（歩留まり・残粉回収など）は小さいグレー文字

2. 配合
   【下味】漬け込み時間つき
   【衣】

3. 工程
   丸数字。温度と時間を必ず入れる

4. 注意点
   ・で始める。失敗しやすい点を先に書く
   ・最後に「仕入単価が変わった場合は原価表を更新すること」
```

## 実装メモ

- `docx` ライブラリ（Node）を使う。フォントは `Yu Gothic`。
- アクセント色は料理系 `8C2E1B`（レンガ）、記録系 `1F4E4A`（深緑）。
- 表のセルは `verticalAlign: CENTER`。列幅は 材料を広く、数値列は右寄せ。
- 作ったら必ずPDFに変換して画像で目視確認する。1ページに収まったか確認するまで完了としない。

## 社内LINE用テキスト

docxとは別に、LINEにそのまま貼れるプレーンテキストを用意する。

- 表組みは使わない。`■` で節、`・` で項目。
- 数字は「1個 約71円 ／ 100g 約197円」のように併記。
- 現場向け簡潔版と、原価表つき詳細版の2パターン出す。
  キッチンのグループに投げるだけなら簡潔版、新人に渡すなら詳細版。
