# 【ススデパ】アセット.xlsx の構造

社内で既に運用されている「アセット・レシピ管理システム」。
所有者は別の担当者。共有で複数人が触るため、**構造を作り替えず、配線を通す方向で直す。**

## シート構成

| シート | 役割 |
|---|---|
| `00_ダッシュボード` | 登録商品数・平均原価率・原価率アラート |
| `01_商品マスター` | 商品ID / カテゴリー / 商品名 / 売価 / 原価合計 / 原価率 / 粗利 / オペ負荷 / 仕込み内容 / 工程 / 品質注意 |
| カテゴリー別レシピシート20枚 | `コース` `一品` `サラダ` `肉類` `中華` `浜焼き海鮮` `かに` など |
| `食材単価マスター` | 約930行。仕入先別の実勢単価 |
| `カテゴリー` | 分類のマスタ一覧 |

## すでに組まれている式（壊さない）

レシピシート G列：

```
=IFERROR(VLOOKUP(D2, '食材単価マスター'!$B$2:$H$6924, 7, FALSE), 0)
```

レシピシート H列：`=E2*G2`

商品マスター F列（原価合計）：

```
=IFERROR(SUMIF(INDIRECT("'"&B3&"'!A:A"), A3, INDIRECT("'"&B3&"'!H:H")), 0)
```

商品マスターの B列（カテゴリー）がレシピシート名と一致していることが前提。
`INDIRECT` でシート名を組み立てているため、**シート名を変えると全部壊れる。**

## 原価が0になっていた原因

1. `食材単価マスター` の H列（グラム単価）が **13行目までしか入っていなかった**。
   参照先が空なのでVLOOKUPが空を返し、`E*G` が0になる。
2. レシピシートの食材名がマスターの正式名と一致していない。

## 直し方

1. `食材単価マスター` の全行に F（入り数）・G（歩留まり 1.0）・H（`=IFERROR(D{r}/F{r}/G{r},"")`）を入れる。
   仕入単価が数値でない行（時価品）はスキップし、空欄のまま残す。
   既に入っている歩留まり実測値は**上書きしない**。
2. 各レシピシートの K列に照合フラグを足す：

```
=IF($D2="","",IF(ISNA(MATCH($D2,'食材単価マスター'!$B$2:$B$934,0)),"未登録","OK"))
```

3. 同名重複を洗い出して報告する。VLOOKUPは上の行しか拾わないため。

## 残っている入力作業

- レシピシート20枚が全部「海鮮ミルフィーユ丼」のコピーのまま。実際の料理に差し替える。
- 商品マスター97品のうち売価が入っているのは6品のみ。
- 歩留まりは既定100%。実測が出たものだけ上書き。

97品すべてを埋めるのは現実的でない。**金額の大きい上位10品から**着手する。
