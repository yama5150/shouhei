# 文言と見せ方の型

ススキノデパート（札幌・すすきの）のバイキング／寿司。3 本作って固まった
ところをまとめる。

## 構成の型

**掴み → 中身 → 締め → ロゴ → 黒**

| | 中身 | 尺の目安 |
|---|---|---|
| 掴み | いちばん強い絵。色があるもの、動くもの、大きいもの | 1.0〜2.4秒 |
| 中身 | 仕入れ → 仕込み → 出来上がり、または 飾り → 料理 → 人 | 1 カット 1.4〜2.4秒 |
| 締め | 告知カード（店名・内容・誘導） | 2.0〜3.6秒 |
| ロゴ | 店のロゴテンプレ。素材のまま（`plain: true`） | 2.0秒 |
| 黒 | 音を引き切るための余白 | 0.4〜0.6秒 |

全体 15〜30 秒。素材が薄いときは無理に伸ばさず 15 秒で締める。

**流れのつくり方**: 同じものを前後でつなぐと効く。生の秋刀魚を仕入れの
ところに置いて、後半に秋刀魚の握りを置くと「届く → 握りになる」の線が
できる。ばらばらの絵を並べるより記憶に残る。

**一拍おく**: 文字を乗せないカットを 1 つ挟むと、詰まった印象がほどける。
料理と人のあいだ、または山場の前。

## テロップ

下寄せの小さめチップ。切り替えは全部ハードカット。凝った転換は使わない。

- 1 カット 1 行、長くても 2 行。読み切れる量にする
- 体言止めか「〜ます」。敬語を混ぜすぎない
- 品名は言い切らない。日替わりで替わるものは「本日の地魚と、貝。」
  「その日 入った貝。」のようにぼかす。名指しして外れると困る

### 言わないこと

- **裏取りできない鮮度の言い切り**。「生きたまま」「朝獲れ」などは、
  こちらで確認できないなら書かない。「いいのが入ってます」に逃がす
- **未確定の日付と価格**。決まるまでは「近日開催」。企画書の方針でも
  「まず出せる数を確定させたうえで告知量を設計する」となっている
- **画に無いもの**。本文で触れるのは構わないが、テロップで名指しするなら
  その絵があること

### 実際に使った言い回し

```
今日、こんなん入りました。        魚は その日のぶんだけ。
本日の地魚と、貝。                真鯛は 一本もの。
一尾ずつ、手で。                  貝は、目の前で開ける。
開けたてが、いちばん旨い。        その日入荷した、旬の魚介で。
彩り、揃ってます。                できたては、お席まで。
愉快な仲間たちが お出迎え。        貴方様を おまちしております
```

## 速い版（SNS のグルメ動画の型）

プロのグルメアカウントが店を撮った 42 秒の動画を実測した。ふだんの型より
だいぶ速い。テンポを上げたいときはこちらに寄せる。

| | 実測値 |
|---|---|
| 1 カット | **中央値 1.1 秒**（0.8〜1.4 秒、42秒で 38 カット） |
| テロップ | **下地なし。白文字＋黒の縁取り** |
| テロップの高さ | 画面の **0.53〜0.55**（1920 なら y≈1050）。ふだんの 1410 より**ずっと上** |
| 文字サイズ | 1920 換算で 50〜60px |
| 掴み | 最初の 3 秒に**大きな文字**。「これも」→「全部食べ放題」と繋ぐ |
| 文の切り方 | 1 カット 1 フレーズで、**次のカットに続く**（「握って、」→「炙って、」） |
| 締め | **店の看板の実写**。駅名・階数・営業時間がそのまま映る |
| 音 | -15.1 LUFS / 真ピーク -1.5 dBFS。うちの -16 より強め |

**効いているのは 3 つ。**

1. **テロップが画面の中央寄り。** 下に置くとアプリの UI と競合するし、
   目線も落ちる。真ん中なら絵と文字を一度に読める
2. **下地を敷かず縁取りで読ませる。** チップは情報っぽく見える。
   `chip: "0x000000@0.00"` + `caption_border: 8` でこの形になる
3. **数字を言う。** 「150種類以上」「約100種類以上」。
   ただし**裏取りの取れた数字だけ**。店の黒板に出ている数字でも、
   こちらで確認してから使う

真似しないところ: 一人称のくだけた語り（「めちゃ美味い」「たまらんやつ」）。
あれは客側のアカウントの声で、店の公式でやると安っぽくなる。店の声は
体言止めか「〜ます」のまま、テンポだけ上げる。

## 色

厨房も客席も暗いので、そのまま出すと沈む。**画面の平均輝度を 110〜160
（0-255）に揃える**と見やすくなる。

- 動画クリップは 130〜160 あることが多く、たいてい無調整でいい
- 写真が沈みがち。黒い作務衣が写ると 70〜90 まで落ちる
- フラッシュで顔が飛んでいる写真は、持ち上げすぎると余計に潰れる。
  平均が低くても `lift` は 1.3 までに留める

出来上がりを測って詰める。`inspect_sources.py` が素材側の目安を出す。

## サムネ

- 地は**食べ物か人**。いちばん「おっ」となる絵
- タイトルはおどけた丸ゴシック（モトヤLマルベリ）＋太い縁取り＋傾き
- 絵文字を入れると勢いが出る。🎃🧑‍🍳⁉️ など
- **中央 1:1 に収める**。一覧ではそこしか見えない

## 投稿文

本文は短く、動画のテロップと同じトーンで。価格と未確定の日付は入れない。

```
その日入荷した、旬の魚介で。

真鯛は一本もの。
貝は、目の前で開ける。
握りたてを、そのまま出します。

熟成赤酢のシャリで握る
「蟹とお寿司の ススデパ秋祭り」近日開催。

その日入った様々な秋の旬ネタを揃えてお待ちしております。

日程が決まりしだい、こちらでお知らせします。
ご予約・詳細はプロフィールのリンクから。
```

ハッシュタグは 15〜20 個。地域・業態・品目の順で。

```
#ススキノデパート #すすきの #すすきのグルメ #札幌 #札幌グルメ
#札幌ディナー #北海道グルメ #バイキング #食べ放題
（+ その回の品目: #寿司 #握り #赤酢 #海鮮 #焼肉 #ハロウィン など）
```

画に無いものをハッシュタグで出すかは、集客と誠実さの兼ね合い。迷ったら
外して、撮れてから足す。

## 出すもの

1 回ぶんの納品は 3 点。

| | |
|---|---|
| 本番用 mp4 | 曲入り。そのまま投稿できる |
| 無音版 mp4 | アプリ内の音源を使う場合 |
| サムネ jpg | 投稿画面の「カバーを編集」で選ぶ |

本文とハッシュタグはチャットに貼る。長く使うなら `caption.md` に残す。

Instagram のリールは**アプリ内の音源を使ったほうがリーチ面で有利**なので、
無音版も毎回出しておく。曲入りは自社サイト・LINE・YouTube 向け。

## 素材として使わないもの

渡された中に紛れていることがある。公開物には入れない。

- 他人の SNS のスクリーンショット
- **他人が撮って投稿した動画**。店を撮ってもらったものでも、著作権は撮った人に
  ある。ダウンロード版は TikTok のロゴとアカウント名も焼き込まれている。
  **構成・テンポ・テロップの位置を参考にするのは問題ない**（やり方そのものは
  誰のものでもない）。**ダメなのは絵をそのまま自分の投稿に使うこと。**
  使いたいなら本人に連絡して、許可をもらってリポストするか、タグ付け・
  コラボ投稿にする。そのほうが相手にも得なので、だいたい話は通る。
  カット割りもテロップの文言も丸ごと同じ、という寄せ方だけは避ける
- 社内のやりとり（LINE など）。人名・勤怠・予約数などが写る
- 顔が写っていて、出していいか分からない人

気づいたら黙って外さず、**外したことを伝える**。誤添付のこともあれば、
本人は気づいていないこともある。
