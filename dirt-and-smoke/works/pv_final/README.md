# 完成PV（姉妹版・約3分）

| ファイル | 中身 |
|---|---|
| `DIRT_AND_SMOKE_PV.mp4` | **完成品**。1920×1080・30fps・3分3秒 |
| `index.html` | Web版（スマホは横向き推奨）。MP4と同じ絵を、同じ時間で描く |

| `mix.py` | 音の組み立て（子守唄の速さと音程を落とす、息の音、主題歌の入り） |

| `font/` | 明朝体（Noto Serif JP、OFLライセンス） |

## 構成
| 時間 | 内容 |

| 2:55 | 無音の黒に「おやすみ。」 |

## 作り直すとき（Claude 用メモ）
1. `timeline.js` の秒数を直す。音に関わる秒数を変えたら `mix.py` も合わせる
2. 音：`python3 mix.py` → `mix.m4a`
3. 映像：`dirt-and-smoke/` を http で配信し（例：`python3 -m http.server 8765`）、次を実行（30fps・183秒で約8分）
   ```
   node works/pv_final/tools/render.cjs "http://localhost:8765/works/pv_final/index.html?render" works/pv_final/mix.m4a 出力.mp4 30 183
   ```
   `index.html?render` を開くと、外から `__draw(秒)` を呼んで1コマずつ描ける。`render.cjs` はそれを画像にして ffmpeg に流し込む（playwright と ffmpeg が必要）
4. 確認：MP4から数コマ切り出して目で見る

## 総監督の判断
- 融合した顔の0.2秒カット（2:12）は入れない（入れる前の版の方が怖い）。絵は `assets/img/fusion.jpg`
- 「心の闇が　本当の私」の歌詞が出るタイミングは、音量から推定したもの。ずれていたら曲の秒数を聞いて直す
