# 決定事項：PVの構成は C 案

総監督・シナリオ（Claude）・ビジュアル（ChatGPT）の全員一致で決定。

## C案：前半は美しく、一番静かなところで予告なく崩す
- 美しさを「罠」にする。見る人が油断したところで、取り返しのつかない形に崩す
- 参考にした構造：「安全な日常の、一番温かい瞬間に、予告なく、取り返しのつかないことが起きる」（ゴアは使わない）

## 具体
| 区間 | 内容 |
|---|---|
| 前奏〜曲の前半 | 冷たい灰色。顔のアップ・涙・畳み掛けカットは出さない。違和感は「少しだけおかしい」程度 |
| 一番温かい記憶（約2:40〜3:25） | 歌う少女 → 夢の台所「わたしの、かわいい子」→ 手袋「私は、眠るのが怖い」「私も」「手を握った。」 |
| 崩れる（ブリッジ・約3:27） | 予告なしに曲の音を0.8秒消して暗転 → 2秒で11枚を畳み掛ける → 黒に「どちらの手が。」 |
| 余波（最後のサビ〜） | 美しい絵には戻らない。後ろを向く鏡、動く鏡、誰も映っていない鏡、紫の「私」、灰の街 |
| 曲のあと | 無音 →「おやすみ。」 |

## 次にやること
1. ビジュアル：前半用の「美しいけれど少しだけおかしい」絵、後半を崩すための不足素材
2. 曲の区切り（特にブリッジの一番静かな瞬間）の正確な秒数を総監督に確認
3. 動画ファイル（MP4・16:9）に書き出す
