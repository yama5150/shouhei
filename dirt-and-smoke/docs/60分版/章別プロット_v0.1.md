## 0. この版の芯

**感情の核【提案】**
「おやすみ、と言ったのは、どちらだったのか。」

**三本の柱**
1. **愛は本物**：髪を梳かす、数を数える、子守唄。日常の手触りで伝える
2. **行為は許されない**：記録帳の淡々とした文字と、他人の生活の痕跡（指輪の跡）で伝える。ゴアは使わない
3. **最後は誰なのか分からない**：「私」の色、鏡、記憶の視点で崩す

**後味の狙い**
プレイヤーが第二章で感じた「幸せ」を、第四章で思い出して戸惑う。あの子守唄が、他の誰かにも歌われていたと知るからです。

## 1. 人物

### 少女（妹の形をした少女）【継承＋提案】
- 名前は最後まで不明。16歳前後、正式ビジュアルを維持。目覚めた時点で縫い目は23本
- 「私」を知らない。第二章で姉の口癖から「わたし」を覚え、第三章で記録帳の字から「私」を覚える
- **数える癖**は、姉が教えた遊びから来ている【提案】
  - 幼い妹が暗がりを怖がると、姉は「数えてごらん」と言った
  - 少女が縫い目や天井の染みを数えるのは、誰かに教わった怖さのしのぎ方
- 善悪をまだ知らない。だから、姉の罪を知っても**最初は嬉しい**と感じてしまう。プレイヤーはそこに戸惑う

### 姉【継承＋提案】
- 妹を失った女性。夜な夜な体の一部を集め、妹を作り直してきた
- **喪服の黒いヴェールで、いつも顔が見えない**【提案】
  - 家で人が死ぬと鏡を覆う、ヴィクトリア朝の喪の習慣と同じ理由づけ
  - 顔を描かない理由が、物語の中で自然に成り立つ
- **いつも手袋をしている**（旧博士から継承）。手袋の下は土と傷で荒れている
- **眠らない**【提案】
  - 妹は「おやすみ」と言われた夜に、眠ったまま死んだ（死因は明かさない）
  - それ以来、姉は眠るのが怖い（Somnus Phobia）
  - 最後の「おやすみ。」は、姉が妹にかけた最後の言葉でもある
- 「私」は青。最初から声に出して使う（旧博士との違い）
- 優しい。だが、妹が外に出ること、窓を開けること、自分以外の誰かを思い出すことを嫌う。愛と独占の区別がついていない

### 名前の扱い【提案】
- 姉は少女を名前で呼ぶ。だが画面では、**名前の部分が必ずインクの染み「■■」**になる
- 記録帳の「声帯（塗りつぶし）」と同じ。プレイヤーは最後まで、その名を読めない

## 2. 継承する仕掛けの意味（姉妹編での再定義）

| 仕掛け | 姉妹編での意味 |
|---|---|
| 鏡が現実に先行する | 鏡には「最後に目覚める存在」が先に映っている。だから少しだけ先に動く【提案】 |
| 夢の視点が姉側へ移る | 姉がまだ生きているうちから、少女は姉の記憶を見てしまう。鏡と同じく、未来から記憶が漏れている（作中で説明はしない） |
| 縫い目 23 → 24 → 25 | 24本目は他人の薬指（指輪の跡）。**25本目は胸。最後の一片** |
| 記録帳（青いインク） | 姉の日記と作業記録。**心臓の欄だけ空白**。終盤で「心臓　私《青》」と埋まる【提案】 |
| 「私」の色 | 青＝姉、赤＝妹、白＝境界の消失、紫＝最後の意識（終章で一度だけ） |

| 「おやすみ。」 | 妹への最後の言葉。集めた相手への言葉。そして終章の、誰のものか分からない言葉 |

## 3. 章別プロット

### 第一章　目覚め（約10分）
**狙い**：異様さと、優しさの手触りを同時に置く

1. **灰と煙の中で、私《白》は目を覚ました。**（プロローグ。2周目は「また目を覚ました」）
2. 研究室の寝台。天井の染みを数える。縫い目を数える。二十三本
3. 布のない鏡。**鏡の少女が、先に微笑む**
4. 足音。喪服のヴェールの女。顔は見えない
   - 姉「おはよう、■■」「……覚えてないのね。いいの。私《青》が覚えてるから」
5. スープ。言葉を教わる（さじ、ろうそく、鏡）。覆われた鏡には触れないこと
6. 夜。姉「眠りなさい」少女「あなたは、眠らないの」姉「……私《青》は、いいの」
7. 【選択：眠る／眠らない】どちらでも身体は眠る
8. 夜中に一度だけ目が覚める。寝台の横の椅子に、ヴェールの影。小さな声で、数を数えている
   - 「……ひゃくにじゅう、ひゃくにじゅういち……」
   - 少女が息をするたびに、数えている

**章の終わりの一行**：「その夜、私は、自分の息の数を知らなかった。でも、誰かが知っていた。」

### 第二章　優しい記憶（約12分）
**狙い**：プレイヤーに、姉妹を好きになってもらう。この章は徹底して温かく

1. **朝の髪梳き**（毎朝の儀式として繰り返す）
   - 姉が櫛を通しながら数える。「ひとつ、ふたつ……」。百まで
   - 少女も一緒に数えるようになる。数える癖の始まりが、ここで見える
2. 姉は少女の冷たい手を、手袋ごしに温める。「冷たいね。昔からそう」
3. 夢：台所。鍋をかき混ぜる女の背中。スカートを握る小さな手
   - 「わたしの、かわいい子」 → 少女は「わたし」を覚える
4. 目覚めると子守唄を口ずさんでいる。姉の手が止まる。それから、泣くような声で一緒に歌う
5. 小さな日常（2〜3場面）
   - 窓の煤に、指で絵を描く遊び
   - 姉が古い本を読み聞かせる
   - 少女が初めて冗談のようなことを言い、姉が笑う。**ヴェールの下で、笑い声だけが聞こえる**
6. **二度目の台所の夢で、視点がずれる**（最初の小さな食い違い）
   - 見下ろすと、小さな手が自分のスカートを握っている
   - 少女は気づかない。プレイヤーだけが「今、誰の目で見ていた？」と引っかかる
7. 姉「ずっと、一緒にいようね」
8. 夜。少女は姉の言いつけで、もう眠ったふりができるようになっている
   - 扉の閉まる音。雨。姉が外へ出ていく
   - 朝方、戻ってくる足音。裾から、川と土の匂い

**章の終わり**：左手の指先が、少しだけ、自分のものではない匂いがする。

### 第三章　継ぎ接ぎの愛（約13分）
**狙い**：愛の正体を、記録の文字で静かに見せる。少女はまだ怖がらない

1. 姉の外出中。書斎の記録帳（青いインク）
   - 部位ごとの記録：左手　洗濯女　二十六歳／右眼　不明／声帯（塗りつぶし）／**心臓（空白）**
   - 日付ごとの記録：「三体目、歌った。違う。」「五体目、私《青》の名を呼ばなかった。」「七体目。今度こそ。」
   - 記録帳の最後の一行：「――今、帳面を読んでいる。」インクが乾いていない（旧稿から継承）
2. 頁の間に、古い写真（ヴィクトリア朝の**遺体写真**の習慣【提案】）
   - 並んで座る姉妹。妹の目は、閉じた瞼の上に絵の具で描かれている
   - 姉の顔だけが、引っかいて消されている
3. 少女は、それを読んでも**嬉しい**と感じてしまう
   - 「こんなに何度も、私《赤》を作ってくれた」
   - ここで初めて「私」を使う。色は赤。記録帳の字を窓の煤に写して覚える
4. 鏡を見る。鏡の中の少女の薬指に、糸が一本。自分の指には、まだない
5. 夜。足音が扉の前で止まる。【選択：眠る／眠る】
6. 朝。縫い目、二十四本。**左手の薬指。指輪の跡の上を、糸が横切っている**
7. 少女はその指輪の跡を見つめる
   - 「この指輪をしていた人は、誰の帰りを待っていたのだろう」
   - 少女が初めて、自分以外の誰かのことを考える。**最初の倫理の棘**
8. 姉は新しい指を見て、静かに喜ぶ。「よかった。これで、手をつなげるね」

**章の終わり**：少女は、自分が誰かを待っているのか、誰かに待たれていたのか、分からなくなる。

### 第四章　許されない願い（約12分）
**狙い**：愛の裏側を見せる。第二章の幸せを、プレイヤーの中で汚す

1. 少女は初めて、言いつけを破って夜の外へ出る。灰の降る街
   - 街角の貼り紙：行方の知れない女たちの名前と年齢。「洗濯女　二十六歳」の字を、少女は知っている
2. 墓地か、運河のほとり（どちらにするかは未決）。ヴェールの姉の後ろ姿
   - 姉は、横たわる誰かの傍らに膝をつき、**子守唄を歌っている**
   - 「……おやすみ」
   - 何をしているのかは見せない。見せるのは、手袋の手と、歌と、雨だけ
3. 少女は逃げ帰る。初めて、自分の体を怖いと思う。この指も、この目も、誰かの「おやすみ」の後に来た
4. 姉が帰ってくる。起きて待っていた少女と、向かい合う
   - 姉は言い訳をしない。「ごめんね。でも、もう一度、あなたに会いたかった」
   - 少女「わたしは、その子なの」　姉「……そうだって、言って」
   - **姉が求めているのは答えではなく、そう言ってもらうことだと、少女は分かってしまう**
5. 少女が自分の胸に手を当てる。鼓動がない
   - 姉「最後のひとつが、まだなの」
   - 少女「もう、集めないで」
   - 姉「……じゃあ、最後のひとつは、どこから持ってくればいい？」
6. 【選択：姉の手を握る／振りほどく】
   - 「振りほどく」を選ぶと：「振りほどこうとした。この手は、言うことを聞かなかった。洗濯女の左手は、姉の手を握り返していた」
   - どちらを選んでも、手は握られている
7. 鏡。布の一枚が、内側から膨らむ。顔の形

**章の終わり**：その夜、初めて、姉が眠っているのを見た。椅子の上で。少女は、それがとても怖かった。

### 第五章　最後の一片（約9分）
**狙い**：二人の境界を溶かす。少女自身の意志で、最後の行為をさせる

1. 最後の夜。姉が少女の髪を梳かす。百まで数える。今夜は、九十九で止まる
2. 姉が語る（短く）。妹は「おやすみ」と言った夜に、眠ったまま戻らなかった。それから、眠るのが怖い
   - 姉「今夜は、眠れそうな気がする」
3. 記録帳の最後の頁を、姉が少女に見せる。心臓の欄に、青いインク
   - **心臓　私《青》**
4. 姉は手袋を外す。少女は初めて、姉の素肌の手に触れる。温かい
5. **最後のひと針は、少女が縫う**【提案】（主人公の意志。選択肢は出さない）
   - 姉「上手ね。教えたとおり」　少女は教わった覚えがない。でも、手が知っている
6. 少女が歌う。今度は、少女が姉に子守唄を歌う
7. ここから名前表示が消え、「私」はすべて白
   - 「私《白》は、眠るのが怖い」「私《白》も」
   - 手を握った。どちらの手が。
   - 私《白》は歌った。私《白》は眠った。
8. 縫い目を数える声。二十三、二十四……二十五
9. 「おやすみ」
   - **誰が言ったのかは書かない**（名前表示なし、色なし）
   - 蝋燭が消える

### 終章　おやすみ。（約4分）
**狙い**：答えを出さずに、感情だけを残す

1. 朝。姉の足音がしない。数える声もしない。椅子の肘掛けに手袋が片方。もう片方は、私《白》の手に嵌まっている
2. 覆われた鏡の布を、一枚ずつ外す。数えない
3. 最初の部屋の鏡の前。少女は、誰かがしてくれたように、自分の髪をそっと撫でる
   - 鏡の中の少女も同じ仕草をする。**だが、ほんの少しだけ先に始まっていた**
4. 少女は微笑む。それが誰の微笑みなのかは分からない
5. 扉を開ける。灰が降っている。赤い月
6. 主題歌「Dirt and Smoke」（エンドロール）。最後のサビで、一度だけ紫の「私」
   - 「心の闇が　本当の私《紫》」
7. 曲が終わる。無音の黒
8. **おやすみ。**

## 5. 分量と実装

### 分量
- 本文 約20,000〜24,000字（スマホ1タップ1〜3行、読む速さ1分あたり約350〜400字）
- 選択肢は3回（眠る／眠らない、眠る／眠る、握る／振りほどく）。どれも結末は変わらない
- 最後のひと針には選択肢を出さない

### 実装【提案】
- 既存のエンジンを横画面対応にする。絵は画面いっぱい、文字は下の窓
- 台本を章ごとのファイルに分ける。シナリオを章単位で追加・差し替えできるように
- **絵がまだない場面は、仮の黒背景と場面名で進む**。絵が届いたら名前を合わせて置くだけで差し替わる
- 60分あるので、**章ごとの続きから再開**と章選択（クリア後）だけは入れる。それ以外の機能は増やさない
