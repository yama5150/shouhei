# 第五章クライマックス「イタイ」演出案 v0.1
### 総監督・ビジュアルディレクター発案／シナリオ担当（Claude）による組み込み案

---

## 1. 組み込む場所

第五章の流れ（プロット v0.1）の「最後のひと針 → 少女が歌う」の直後に置く。
感情の流れを次の順にする。

| 段階 | 感情 | 文字 |
|---|---|---|
| ① 気づかい | 妹が姉を心配する | 赤と青。言葉はまだ意味を持っている |
| ② 反復 | 言葉が意味を失い始める | 色が「私」の一文字からはみ出し、言葉全体に滲む |
| ③ 願い | 痛みが「居たい」にすり替わる | 赤と青が入れ替わり、誰の台詞か分からなくなる |
| ④ 崩壊 | 漢字が一瞬だけ化ける | 遺体・異体が、一瞬だけ映って消える |
| ⑤ 消失 | 意味が消え、音だけが残る | ひらがなの「いたい」。色なし |
| ⑥ 静けさ | 融合のあとの凪 | 白。名前表示なし |
| ⑦ 着地 | 「ずーっと……一緒……」「汚れたワタシタチが、本当の私。」 | 白 |
| ⑧ 終わり | 「おやすみ。」 | 色なし |

**痛み → 願い → 消失 → 凪**の順にすることで、怖さのあとに静けさが来る。
「願いが叶った瞬間に、願いの意味が消える」を、プレイヤーは静けさの中で感じる。

---

## 2. 言葉遊びにしないための工夫

1. **4つの漢字を並べない。** 遺体と異体は、正式な台詞としては一度も出さない。文字が書き換わる途中の一瞬（0.06〜0.1秒）にだけ映る。気づかない人もいてよい
2. **書き換えの演出は、第一章から仕込んでおく。** 第一章の「鏡の方は、見ない。」→「鏡の方を、見ている。」のように、文字が勝手に書き換わることを、プレイヤーは序盤で学んでいる。だから漢字が化けても駄洒落に見えず、「あの力がまた動いた」と感じる
3. **プレイヤーの操作を奪う。** 反復が始まったら、タップを待たずに文字が勝手に進む。少しずつ速くなる。自分の意識が自分のものでなくなる感覚を、指で体験させる
4. **意味を説明しない。** 地の文は一切入れない。台詞と沈黙だけ

---

## 3. 色の扱い（この場面だけの例外）

- 通常、色がつくのは「私」の一文字だけ
- この場面だけ、**色が「私」からはみ出し、台詞全体に滲む**（境界が壊れたことの表現）
- 赤（妹）と青（姉）が交互に → 入れ替わる → 一文字ずつ赤と青が混ざる → 白 → 色なし
- 紫は使わない。紫は終章の主題歌の一行にだけ残す
  - 融合した瞬間には、目覚めた意識はまだ誰でもない。誰になったのかが分かるのは、朝になってから（＝分からない）

---

## 4. 音

- 少女の子守唄（Unplugged）が流れ続ける
- 反復が始まると、**曲の再生速度を少しずつ落とす**（音程も下がる。1.0 → 0.85 → 0.7）。歌が溶けていく
- 「いたい」（ひらがな）が出た瞬間に、**曲を完全に止める**。3秒の無音
- 総監督の案「音声は同じイタイ、文字だけが変化」について
  - このエンジンにはボイスがないので、2案
  - A：ボイスなし。代わりに、どの「イタイ」が出るときも同じ小さな音（息を吸う音）を鳴らす。音は同じ、文字だけが変わる
  - B：「いたい」と囁く声を一つだけ録音してもらう（総監督の声でも、合成でも）。それを毎回同じ音で鳴らす
  - 推奨は B。同じ声が、違う漢字に聞こえてくるのが一番怖い

## 5. 台本ドラフト

凡例：《赤》《青》《白》は色。〔一瞬：○○〕は0.06〜0.1秒だけ映る文字。【自動】はタップを待たずに進む。

```
（最後のひと針。少女が歌い終える）

糸を、結んだ。

姉の手が、ふるえている。

「お姉ちゃん」《赤》

初めて、そう呼んだ。
誰に教わったのでもなく、口が知っていた。

「お姉ちゃんも……痛いよね？」《赤》

「……痛くないよ」《青》

うそだ、と思った。
うそという言葉を、私《赤》は知らなかったのに。

「痛いよね？」《赤》

【自動】
「痛いよね？」《赤》
「痛いよね？」《青》         ← 同じ台詞が、姉の色で返ってくる
「痛いよね？」《赤》
「痛い」《青》
「痛い」《赤》
「イタイ」《青》
「イタイ」《赤》
「イタイ、イタイ、イタイ」  ← 一文字ずつ赤と青が混ざる

（曲の速さが落ちていく）

「……居たい？」《青》

【自動・止まる】

「まだ、居たい？」《赤》       ← 姉の問いを、妹の色で

「居たい」《青》
「居たい」《赤》

「ずっと、居たい」             ← 一文字ずつ赤と青

「イタイ」
　〔一瞬：遺体〕
「イタイ」
　〔一瞬：異体〕
「イタイ」

（文字が一文字ずつ消える）

「いたい」                     ← ひらがな。色なし

（曲が止まる）
（無音・3秒）

（名前表示はもうない）

「私《白》は、眠るのが怖い」
「私《白》も」

手を握った。
どちらの手が。

「ずーっと……」
「……一緒……」

縫い目を数える声がする。
二十三。二十四。

二十五。

「汚れたワタシタチが、本当の私。」

（蝋燭が消える）

おやすみ。
```

## 6. 主題歌への接続

| 第五章の言葉 | 歌詞 |
|---|---|
| 「汚れたワタシタチが、本当の私。」 | それでも汚れは落ちない／だってそれが私だから |
| 同上 | 心の闇が　本当の私（終章の主題歌で、ここだけ紫） |
| 「いたい」の後の無音 | Don't close your eyes |
| 「おやすみ。」 | 灰と煙の中で／新しい私が目を覚ます |

第五章で「本当の私」と言ったのが誰なのか分からないまま、終章の主題歌が同じ言葉を歌う。そこで初めて、紫の「私」が出る。

## 7. 提案（総監督の判断待ち）

1. **少女が初めて「お姉ちゃん」と呼ぶのを、この瞬間にする**
   - それまで少女は姉を何とも呼ばない（「あなた」すら使わない）
   - 一番近づいた瞬間が、崩壊の始まりになる
2. **姉の最初で最後の嘘「……痛くないよ」**
   - 嘘を知らない少女が、嘘だと分かってしまう。その瞬間に、姉の記憶が少女の中に入っている
3. **「ワタシタチ」はカタカナ。** 「私」の漢字と色を失った、誰のものでもない一人称
4. 第五章の「おやすみ。」と終章の最後の「おやすみ。」は、**同じ言葉を二度**使う
   - 一度目は、誰かが誰かに言った言葉
   - 二度目は、画面のこちら側（プレイヤー）に言われる言葉
