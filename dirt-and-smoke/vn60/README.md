## 章を足すとき
1. `chapters/ch2.js` を `ch1.js` と同じ形で作る（`(window.CHAPTERS=…)[2]={title,sub,script}`）
2. `index.html` の「章を書いたら、ここに1行ずつ足す」の下に `<script src="chapters/ch2.js"></script>` を足す
3. 最後の章のあとは自動で「（つづく）」になる

## 台本の書き方
- 1行＝1タップ。空行＝ページを替える（ここで自動保存）
- `@speakers ヴェールの女 姉` … 名前表示をつける話者。`ヴェールの女「……」` と書くと名前つきの台詞になる。名前のない「 」は少女
- `私《青》` `私《赤》` `私《白》` `私《紫》` … 「私」の一文字だけに色
- `■■` … インクの染み（少女の名前）
- 演出命令（画面に出ない）
  - `@img 絵の名前 [night|dark|cold|sepia|smoke]` … 絵（`assets/img/` の名前）。`@img none` で黒
    - **絵がまだない名前を書いてもよい。** 黒い仮の背景で進む。`?debug` をつけて開くと、仮の背景に絵の名前が出る
  - `@bgm lullaby|liar|obscure|obscure_far|theme` ／ `@bgm stop|fade|cut`
  - `@se wind|bell|step|door|chair|cloth|clink|candle|thread|clock|cough|slam`（仮の合成音）
  - `@wait ミリ秒` ／ `@flash red|white` ／ `@bulge`（絵が内側から膨らむ） ／ `@ash on|off`
  - `@rewrite 新しい文` … 直前の一文が消えて書き換わる
  - `@choice 表示>飛び先|表示>飛び先` ／ `*ラベル` ／ `@goto ラベル`
  - `@noname` … 以降、名前表示を出さない
  - `@opening` … 冒頭の一文 ／ `@chaptertitle` … 章扉 ／ `@chapterend` … 章の終わり（次の章へ）

## 検証用
- `?fast&auto` … 自動で最後まで進む（壊れていないかの確認）
- `?ch=1&at=120` … 第一章の120番目の命令から始める
