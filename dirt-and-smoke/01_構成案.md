## 1. 感情的な核【提案】

**「借り物の身体で、たったひとつだけ、自分のものにしたかった。」**

そのひとつが何だったのか──歌か、博士か、彼の眠りか、それとも罪か──は最後まで言わない。

## 2. 主人公

### 名前【提案】
少女に名前はない。博士の記録は日付ごとに彼女を別の名で呼ぶ（「エマ」「リゼ」「七番」……）。
博士自身が、彼女が誰なのかを決められていない。プレイヤーにもそう見える。

### 人物像【提案】
- **見た目の年齢**：15〜17歳ほど。陶器のような白い肌、首・手首・鎖骨に縫合痕。左右で色のわずかに違う瞳。
- **癖：数えること。** 指、蝋燭、縫い目。数えれば自分のものになる気がしている。
  - 「縫い目は二十三本。」 → 二晩目の後「二十四本。昨日は、二十三本だった。」
  - 眠っている間に誰が縫ったのか。博士か、自分か。答えは出さない。
- **言葉が文字どおり。** 比喩や嘘を知らない。だから彼女の語りは静かで、怖い。
- **好奇心は強いが、怒りを知らない。** 怒りに似たものが胸に来ると「これは誰の」と考えてしまう。

### 矛盾と弱さ【提案】
- 眠るのが怖い（Somnus Phobia）のに、身体は眠りたがる。
- 博士が怖い。でも彼の咳が止まると不安になる。
- 他人の記憶を嫌っているのに、子守唄だけは手放したくない。それが一番「他人のもの」なのに。
- **自分の感情を証明できない。** 悲しいのか、悲しかった誰かを思い出しているだけなのか、区別がつかない。

### 博士【提案】
- 老人。煤の街で肺を病み、いつも咳をしている（Dirt and Smoke を身体に溜めている人）。
- **眠らない。** 夜通し椅子に座っている。彼もまた Somnus Phobia ──夢に死者が来るから、と一度だけ漏らす。
- 屋敷の鏡はすべて黒い布で覆われている。**ヴィクトリア朝の「家で人が死ぬと鏡を覆う」喪の習慣**。誰が死んだのかは語られない。布のない鏡が一枚だけ、少女の部屋にある。
- 優しい。けれど、優しさが彼女に向いているのか、彼女の中の誰かに向いているのか分からない。
- 悪人とも善人とも確定させない。

## 3. シーン構成（全9場・約17分）【提案】

本文量の目安：**約6,000〜7,000字**（スマホで1画面1〜3行、1場面あたり30〜60タップ）。

| 場 | タイトル | 時間 | 内容 |
|---|---|---|---|
| 0 | 灰 | 0:30 | 黒。ひとこと「灰と煙の中で、私は目を覚ました。」 |
| 1 | 目覚め | 2:00 | 実験台の上。指と縫い目を数える。鏡の中の少女が**先に**微笑む |
| 2 | 博士 | 2:30 | 博士が来て、彼女を知らない名で呼ぶ。スープ。言葉を教える。「眠りなさい」 |
| 3 | 一夜目 | 2:00 | 【選択：眠る／眠らない】→ 夢：台所で子守唄を歌う女。目覚めると彼女がそれをハミングしている。博士の手が止まる |
| 4 | 記録 | 3:00 | 博士の外出中、記録を読む。部位ごとの死者の名。日付ごとに違う彼女の名。「七体目。今度こそ。」「彼女は歌わない。歌うはずがない。」心臓の欄だけ空白 |
| 5 | 二夜目 | 2:00 | 【選択：眠る／眠らない】→ 汚れた夢：煙の向こうで咳をする男に押さえつけられる。誰の記憶か不明。目覚めると縫い目が一本増えている |
| 6 | 問い | 2:00 | 「私は誰？」博士は名を言いかけてやめる。「明日、少し直そう」 |
| 7 | 子守唄 | 2:30 | 夜。眠れない博士の傍らで、少女が歌う。博士は眠る。蝋燭が消える |
| 8 | 鏡 | 1:30 | 朝。博士は起きない。少女は鏡の布をすべて外す。「あなたは、誰？」鏡の少女は**少し遅れて**微笑む。外へ |
| 9 | Dirt and Smoke | 楽曲尺 | 黒画面（プレイヤーの顔が映る）→ 最後の一文 → 楽曲・エンドロール |

### 構造上の仕掛け【提案】
1. **鏡の「先」と「後」の反転。** 第1場で鏡は彼女より先に動く（＝中の誰かが主導している）。第8場では遅れて動く（＝今は彼女が先にいる）。何が入れ替わったのかは言わない。
2. **冒頭と結末の一文が輪になる。** 第0場「灰と煙の中で、私は目を覚ました。」→ 第9場で同じ文に「それが、二度目だったのかどうかは知らない。」が続く。記録の「七体目」と響き合う。
3. **選択が身体に無視される。** プレイヤーが「眠らない」を選んでも「眠らない、と決めた。／身体は、私の言うことを聞かなかった。」で眠ってしまう。身体が彼女のものではないことを、プレイヤーの指で体験させる。
   そして第7場の行為には**選択肢を出さない**。最後の行為だけは、プレイヤーにも選ばせない。それが彼女の意志だから。
4. **Somnus Phobia を二人が共有する。** 眠るのが怖い少女が、眠るのが怖い老人を眠らせる。それが救いか、殺しか、復讐か、自分を「直されない」ための防衛かは確定しない。

### 第7場の曖昧さを支える材料（どれも確定させない）
- 愛：彼女は彼の手を握り、子守唄を歌う。
- 憎しみ：第5場の夢──咳をする男に押さえつけられた記憶。
- 自己防衛：「明日、少し直そう」「七体目。今度こそ。」
- 何もしていない可能性：彼は病人で、ただ寿命だったのかもしれない。

## 4. 脚本案（要所のみ・ドラフト）

### 第0場　灰
```
（黒。遠くで鐘。煤の降る音）

灰と煙の中で、私は目を覚ました。
```

### 第1場　目覚め（抜粋）
```
天井に、染みがある。
数える。七つ。

指を数える。十本。
左手の薬指にだけ、細い日焼けの跡がある。
指輪をしていた誰かの、跡。

縫い目を数える。
首に四本。手首に六本。胸に……
二十三本。

部屋の隅に、鏡がある。
そこに、少女がいる。

（少女・無表情）
（鏡の少女が、微笑む）

……私は、まだ笑っていない。
```

### 第3場　一夜目（選択）
```
「眠りなさい」と博士は言った。

　▶ 眠る
　▶ 眠らない

［眠らない］
眠らない、と決めた。
身体は、私の言うことを聞かなかった。

［眠る］
目を閉じた。
閉じる前に、鏡の中の私が目を閉じたのが見えた。

（夢：湯気。台所。女の背中。子守唄のハミング）

目を覚ますと、誰かが歌っていた。
私だった。

博士の匙が、床に落ちた。
```

### 第4場　記録（抜粋）
```
左手　　　洗濯女　二十六歳
右眼　　　不明
声帯　　　［塗りつぶし］
心臓　　　

心臓の欄だけ、何も書かれていない。

――十月三日。エマは今日も歌わなかった。
――十月九日。リゼ、指を数える癖。誰のものでもない。
――十一月一日。七体目。今度こそ。
――日付なし。彼女は歌わない。歌うはずがない。
```

### 第7場　子守唄
```
博士は今夜も眠らない。
椅子の上で、咳をしている。

「夢に、来るんだ」
「誰が？」
「……みんな」

私は、彼の手を取った。
冷たかった。私の手より。

「わたしを、恨んでいるか」

答えのかわりに、私は歌った。
台所の女の歌。
私のものではない歌。

博士の咳が、止まった。

　（鏡の少女の手が、博士の喉にある──0.3秒。提案E）

蝋燭が、消えた。
```

### 第8場　鏡
```
朝。
博士は起きなかった。

私は、屋敷じゅうの鏡から黒い布を外した。
一枚ずつ。
数えなかった。

最後の一枚の前に立つ。

「あなたは、誰？」

（少女・かすかに微笑む）
（一拍遅れて、鏡の少女が微笑む）

縫い目を数えるのは、もうやめた。

扉を開ける。
灰が降っていた。
```

### 第9場　Dirt and Smoke
```
（完全な黒。無音。3〜5秒）
（プレイヤーの顔がスマホに映る時間）

あなたは、誰？

（黒のまま）

灰と煙の中で、私は目を覚ました。
それが、二度目だったのかどうかは知らない。

（Dirt and Smoke イントロのアルペジオ）
```

## 6. 「Dirt and Smoke」の配置【提案】

### 楽曲は3回だけ出す
1. **第3場・第7場：子守唄として**（提案B）
   歌メロを、ハミング／オルゴール／ギター単音で。歌詞なし。プレイヤーはまだこれが主題歌だと知らない。
2. **第9場：フル尺（エンディング）**
   最初のアルペジオが鳴った瞬間、プレイヤーは「あの子守唄だ」と気づく。
   ＝**少女が歌っていたのは誰の歌だったのか**、という問いが楽曲によって最後に開く。

## 7. 確定・提案・未決 まとめ

### 【確定】（企画書どおり）
- ゴシック／心理ホラー、スマホ向け、15〜20分
- 煤煙の工業都市、実験室、鏡、赤い月、縫合痕
- 少女は死者の部位から作られた（とされる）
- 真相は明かさない。怪物か人間か確定しない
- 終盤に「あなたは、誰？」と鏡、遅れて微笑む鏡像、灰と煙へ歩く少女、楽曲

### 【提案】（承認待ち）
- 感情の核「借り物の身体で、たったひとつだけ、自分のものにしたかった。」
- 少女は無名／記録ごとに別の名、数える癖
- 博士は肺を病み、眠らない老人。鏡は喪の習慣で覆われている
- 全9場・約17分・6,000〜7,000字
- 鏡の「先→後」反転、冒頭と結末の一文の輪
- 「眠る／眠らない」が身体に無視される選択
- 第7場は選択肢なし

### 【未決】（総監督の判断が必要）
- **A** 人間らしい行為＝子守唄でよいか
- **B** 子守唄に主題歌の歌メロを使えるか
- **C** 選択肢の有無と形
- **D** プレイヤーの顔を映す黒画面を入れるか
- **E** 第7場の0.3秒の鏡の差分を入れるか（入れると「殺した」寄りに傾く）
- 最後の一文：原案のまま／「今度は、誰も私を起こさなかった。」／「縫い目を数えるのは、もうやめた。」
- エンドロール後の一枚（入れる場合：誰もいない部屋の鏡に、少女だけが映っている）
- 楽曲の実際の歌詞（行単位の映像合わせに必要）

## 8. 避けたこと（意図的に入れていないもの）
- 「博士の亡くなった娘を蘇らせようとした」という真相の明言。記録に匂わせる素材はあるが、確定させない。
- 「博士は最初から死んでいた」系のどんでん返し。驚かせるためだけの裏切りになるため。
- ゴア描写の強調。縫い目は「数える対象」として淡々と描く。
