# リールの投稿文

動画・カバーと同じトーンで揃えてある。日程が固まったら「近日開催」の
段落を差し替える（`build_reel.py` の `FAIR_DATES` と一緒に直す）。

## 本文

```
その日入荷した、旬の魚介で。

真鯛は一本もの。
貝は、目の前で開ける。
握りたてを、そのまま出します。

熟成赤酢のシャリで握る
「蟹とお寿司の ススデパ秋祭り」近日開催。

その日入った様々な秋の旬ネタを揃えてお待ちしております。

日程が決まりしだい、こちらでお知らせします。
ご予約・詳細はプロフィールのリンクから。
```

## 日程が決まったら

「近日開催」の行を日付に差し替える。

```
熟成赤酢のシャリで握る
「蟹とお寿司の ススデパ秋祭り」
9/1(火) 〜 10/31(土) 開催。
```

## 書くときに気をつけたこと

- 価格と食べ放題料金は入れていない。企画書の時点で未確定のため
- 日程も同じ理由で「近日開催」。販促は提供可能数が決まってから、という
  企画書の方針に合わせている
- 鮮度の言い切り（「生きたまま」など）は避けて、事実として書ける範囲に
  とどめた
- ネタは品名を挙げずに「その日入った様々な秋の旬ネタ」でまとめている。
  動画のテロップ（「本日の地魚と、貝。」「その日 入った貝。」）と同じ
  ぼかし方。日替わりで替わるものを名指しすると、外れたときに困るため
- ハッシュタグからも `#花咲蟹` は外してある。本文で触れていないのと、
  動画にも画がないため。前に出す方針なら戻してよい
