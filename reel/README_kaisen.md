# 寿司・海鮮コーナーのリール

ススデパの寿司・海鮮まわりだけを集めた 21.4 秒。テロップは**ド派手版と同じ
型**（丸ゴシック＋オレンジ＋太い紫黒の縁取り）。構成ファイルは
`configs/kaisen.json`。

```bash
TITLE_L1="ススデパの" TITLE_L2="寿司・海鮮" TITLE_EMOJI="🍣🦀🐟" \
  /usr/bin/python3 .claude/skills/susudepa-reel/scripts/make_title.py --out reel/out
mv -f reel/out/title.png reel/out/kaisen_title.png

python3 .claude/skills/susudepa-reel/scripts/build_reel.py reel/configs/kaisen.json
```

全幅のまま見せて、上下をぼかしで埋めている。

## 音

`bgm2.mp3` の **136秒から**（136〜157秒、幅 1.6dB の安定区間）。
ほかの 3 本は 89 / 172 / 174秒から使っているので、並べても同じフレーズに
ならない。書き出しは -16.3 LUFS / 真ピーク -4.7 dBFS。

## 言い回しについて

**「のせ放題」は一度書いてから落とした。** 海鮮丼のカットに乗せたが、量の
約束になる。バイキングでセルフなのかどうかこちらで確認できていないので、
「海鮮丼」の一語だけにした。確認が取れたら戻せる（そのほうが強い）。

残してあるが、気になるなら言ってほしい言い回し:

- **「自分で巻く／手巻き」** … 写真が組み立て途中の絵なので画とは合っている。
  ただし提供形態の断定ではある
- **「揚げたて」「切りたて」** … 絵の説明の範囲。企画書に揚げ場と寿司台が
  あるので許容と判断した

## 裏取りが要るもの

- **刺身・サク・海鮮丼・蟹の軍艦・天ぷら・手巻きが、いまも出ているか**
- 蟹の種類は映像から判断できないので「蟹」としか書いていない
- 天ぷらのネタも断定していない（企画書の「イカ天」かどうか不明）
