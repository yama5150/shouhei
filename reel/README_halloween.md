# ハロウィン装飾 + 彩料理のリール

ハロウィンの飾りつけと料理を見せる縦動画（1080×1920 / 30fps / 21.1秒）。

## 出力

| ファイル | 中身 |
|---|---|
| `out/halloween_reel.mp4` | 21.1秒版。BGM 入り |
| `out/halloween_reel_fast.mp4` | **15.7秒版**。カットを詰めて文字を大きくした、TikTok 寄りのテンポ |
| `out/halloween_cover.jpg` | サムネ（1080×1920）。蟹鍋の写真 + おどけたタイトル |
| `out/title.png` | サムネのタイトルだけを描いた透過 PNG |
| `out/halloween_reel_muted.mp4` / `_fast_muted.mp4` | それぞれの無音版 |

速い版は `--fast` で出る。素材は同じで、切り方とテロップだけ違う。

```bash
python3 reel/build_halloween.py          # 21.1秒版
python3 reel/build_halloween.py --fast   # 15.7秒版
```

| | 21.1秒版 | 15.7秒版 |
|---|---|---|
| カット数 | 12 | 14 |
| 1カットの尺 | 1.4〜2.4秒 | 0.8〜1.4秒 |
| テロップ | 56〜64px、下寄せ（下端 1410） | 76〜92px、やや上（下端 1270） |
| 下地の濃さ | 60% | 70% |

速い版は同じクリップの別の場面も使っている（ビビンバの寄り、跳ねる
かぼちゃの着地）。カット数が増えたぶん、絵の種類は減っていない。

## 構成

21.1秒版、全 12 カット。

| # | 尺 | 素材 | テロップ |
|---|---|---|---|
| 1 | 1.8s | 跳ねるジャックオランタン（AI 生成） | ハロウィン、やってます。 |
| 2 | 1.4s | ジャックオランタン（縫い口） | 愉快な仲間たちが お出迎え。 |
| 3 | 1.9s | 巻き寿司の盛り | 彩り、揃ってます。 |
| 4 | 1.7s | サーモンの握り（魚卵のせ） | 握りも、ずらりと。 |
| 5 | 1.7s | 炙りの一皿 | 炙りも、ひと皿。 |
| 6 | 2.4s | IMG_1922 石焼ビビンバを運ぶ | できたては、お席まで。 |
| 7 | 1.9s | 蟹鍋を持つスタッフ | 蟹鍋も、あります。 |
| 8 | 1.4s | ジャックオランタン（笑顔） | — |
| 9 | 2.0s | 職人 + サーモントラウト | ススデパで お待ちしてます。 |
| 10 | 2.4s | 告知カード（かぼちゃをぼかした地） | ススデパの ハロウィン／開催中／詳しくはプロフィールから |
| 11 | 2.0s | 店のロゴテンプレ | — |
| 12 | 0.5s | 黒 | — |

動く絵（跳ねるかぼちゃ）を頭に置いて掴み、飾り → 料理 → 人、の順。
6 カット目のかぼちゃは文字を乗せず、料理と人のあいだの一拍にしている。

頭にフェードインは入れていない（`FADE_IN = 0`）。入れると 1 フレーム目が
黒くなり、ポスター画像に拾われたときに黒い絵が出る。

## 小さい素材の扱い

跳ねるかぼちゃは 480×640 しかない。9:16 に切ると横が 25% 落ちるうえ
3 倍に伸ばすことになるので、`fit="blur"` で幅だけ合わせて（2.25 倍）
全部見せ、余白は同じ絵のぼかしで埋めている。

## 音

元クリップの音は使っていない。ビビンバのカットは -33 LUFS のほぼ無音で、
跳ねるかぼちゃのほうは AI がつけた音。どちらも曲と喧嘩する
（`USE_CLIP_AUDIO = False`）。

曲は `Candlelit Banquet`（2分41秒）。レベルを 1 秒ごとに測ると 34〜35 秒に
区切りがあり、**36 秒から次のセクション**。そこから 55 秒あたりまで
-17〜-20dB で安定しているので `MUSIC_START=37` を既定にしている。
もっと厚いところが欲しければ 134（終盤のいちばん強い区間）。

終わりは告知カードから引きはじめて、ロゴを越えて最後の黒で鳴り終わる
（`AUDIO_TAIL = 3.5` 秒、直線カーブ）。

```bash
MUSIC=/path/to/別の曲.mp3 MUSIC_START=30 python3 reel/build_halloween.py
MUSIC= python3 reel/build_halloween.py        # 無音だけにする
```

## サムネ

`out/halloween_cover.jpg`。蟹鍋の写真に、おどけたタイトルを重ねている。

タイトルは `make_title.py` が透過 PNG に描く。**ffmpeg の drawtext は
カラー絵文字（ビットマップフォント）を扱えず、NotoColorEmoji を渡すと
落ちる**ので、文字と絵文字をまとめて Pillow 側で作って、動画側には画像
として重ねている。縁取り・影・傾きもそちらで付く。

- 書体は モトヤLマルベリ（丸ゴシック）。`apt-get install fonts-motoya-l-maruberi`
- 絵文字は NotoColorEmoji。ビットマップなので 109px にしか開けない。
  原寸で描いてから縮めている
- **Pillow は `/usr/bin/python3` (3.13) に入っている。** `python3` は 3.11 を
  指していて PIL が無いので、実行はフルパスで

```bash
/usr/bin/python3 reel/make_title.py          # -> out/title.png
python3 reel/build_halloween.py --cover-only  # -> out/halloween_cover.jpg
```

文言は環境変数で差し替えられる。

```bash
TITLE_L1="ススデパの" TITLE_L2="ハロウィン" TITLE_EMOJI="🎃👻🎃" \
  /usr/bin/python3 reel/make_title.py
```

Instagram はプロフィールのグリッドでカバーの**中央 1:1 だけ**を切り出すので、
1080×1920 なら y=420〜1500 に収まっているものしか一覧では見えない。
タイトルの位置は `COVER_TITLE_Y`（既定 470）で、この範囲に入れてある。

## 文言を変える

```bash
CARD_LEAD="10/31まで" python3 reel/build_halloween.py
```

テロップそのものは `SEGMENTS` の `lines` を直す。

## 注意

- 1 カット目の跳ねるかぼちゃは **AI 生成動画**。Instagram には AI 生成
  コンテンツの表示ルールがあるので、投稿時に該当するか確認する
- 素材として渡されたもののうち、TikTok の画面と社内 LINE のやりとりの
  スクリーンショットは誤添付と判断して使っていない（個人名と営業情報が
  写っているため）
- `.mov` も `.jpg` も回転メタデータは ffmpeg が自動で当てる。
  `transpose` を足すと二重回転になる
- 元素材はリポジトリに入れていない。`SRC` で渡す
