# 寿司・魚介リール動画

スマホで撮った仕込みの素材から、Instagram リール / TikTok / YouTube ショート用の
縦動画（1080×1920 / 30fps / 33.3秒）を組み立てるビルドスクリプト。

「蟹とお寿司のススデパ秋祭り」（2026/9/1〜10/31）の告知用。企画書の
「派手な演出ではなく、握りたての清潔感と職人の手際そのものを見せる」に沿って、
仕込みの手つきをそのまま見せる構成にしている。

## 出力

| ファイル | 中身 |
|---|---|
| `out/sushi_reel.mp4` | 本番用。「旬 shun」+ 厨房の音 |
| `out/sushi_reel_ambient.mp4` | 厨房の音のみ。包丁・貝を開ける音がそのまま入る |
| `out/sushi_reel_muted.mp4` | 無音版。アプリ側で音楽を乗せたいとき用 |
| `out/cover.jpg` | リールのカバー画像（1080×1920）。握り3貫 |

映像は 1 回だけエンコードして、音声だけ差し替えて 3 本に muxing している。
テロップやカットを触っていないときは `--audio-only` を付ければ映像を作り直さない。

コミットしているのは `sushi_reel.mp4` だけ。ほかは `build_reel.py` を流せば出る。

## 構成

握り → 仕入れ → 仕込み → 出来上がり → フェア告知 → ロゴ の順。全 16 カット、33.3 秒。

生の秋刀魚を仕入れのパートに置いてあり、後半の秋刀魚の握りとつながって
仕入れ→握りの流れになる。

雲丹は季節が終わったので外し、秋刀魚と貝に差し替えた。日替わりで替わるネタなので、
品名を言い切らずぼかしてある。

ロゴのカットは `plain=True` を付けてあり、色調整もテロップも足さずに素材のまま出す。
最後の黒 0.6 秒は音楽を引き切るための余白で、ここがないとロゴの終わりで曲が切れる。

頭にフェードインは入れていない（`FADE_IN = 0`）。フェードを入れると先頭
フレームが真っ黒になり、ポスター画像に拾われたときに黒い絵が出てしまう。
1 フレーム目から握りが出るようにしてある。尻はロゴ側にフェードがあるので
0.2 秒だけ。

## 使い方

```bash
# ffmpeg 6.x と日本語フォント
apt-get install -y ffmpeg fonts-noto-cjk

# 素材を置いたディレクトリを SRC で渡す
SRC=/path/to/素材 python3 reel/build_reel.py

# CTA・フェア告知の文言を変える
CTA="DMでご予約どうぞ" python3 reel/build_reel.py

# 日程が固まったら日付入りに差し替える（既定は「近日開催」の先出し版）
FAIR_DATES="9/1(火) 〜 10/31(土)" FAIR_NOTE="" python3 reel/build_reel.py

# 曲を差し替える／使う位置を変える
MUSIC=/path/to/曲.mp3 MUSIC_START=30 python3 reel/build_reel.py

# テロップもカットも触っていないときは映像を作り直さない
python3 reel/build_reel.py --audio-only
```

素材のファイル名は `build_reel.py` の `SOURCES` で指定している。

## テロップ・カットの調整

`build_reel.py` 冒頭の `SEGMENTS` を触ればいい。

```python
dict(key="tai_v", kind="video", start=9.60, dur=2.80, zoom=1.18, focus=(0.42, 0.58),
     lines=[("まずは 真鯛、一本もの。", 64, INK)]),
```

- `start` / `dur` … 元動画のどこを何秒使うか
- `zoom` / `focus` … 構図の寄せ。`focus` は `(横, 縦)` で 0.0=左/上、0.5=中央、1.0=右/下
- `lines` … `(文字列, フォントサイズ, 色)` を下から積む
- 静止画は `zoom=(開始倍率, 終了倍率)` でゆっくり寄る／引く。`fit="blur"`
  を付けると写真を切らずに全部見せて、余白を同じ写真のぼかしで埋める

テロップの位置は `CAPTION_BOTTOM`（Instagram の UI に被らない高さ）で決まる。

## 素材について

- `.mov` は iPhone の回転メタデータ付き。ffmpeg が自動で縦に起こすので触らない
- `.jpg` は EXIF Orientation=6。これも ffmpeg が自動適用するので、
  `transpose` を足すと二重回転になって上下逆さまになる
- 元素材（合計 48MB）はリポジトリに入れていない

## 色

厨房が暗いので、そのまま出すと沈む。ベースの色調整に加えて、カットごとに
`lift`（ガンマ）で持ち上げ、画面の平均輝度を 110〜160（0-255）に揃えている。

動画クリップはもともと 137〜160 で足りているので `lift` なし。持ち上げが
要るのは写真のほうで、いちばん暗かったのが黒い作務衣のフックカット（70）。

| カット | lift | 調整前 → 調整後 |
|---|---|---|
| 1 職人＋トラウト | 1.45 | 70 → 98 |
| 2 ブリ＋サクラマス | 1.25 | 107 → 126 |
| 9 海鮮丼 | 1.15 | 118 → 130 |
| 10 うに軍艦 | 1.20 | 111 → 128 |
| 11 締めの引き | 1.40 | 83 → 116 |

輝度はこう測れる:

```bash
ffmpeg -i reel/out/sushi_reel.mp4 \
  -vf "fps=1,signalstats,metadata=print:file=-" -f null - | grep YAVG
```

## 音

### 本番用（音楽入り）

`33e8d767-_shun.mp3`（旬 shun）を使う。3分33秒あるので、曲のどこを使うかが
問題になる。レベルを1秒ごとに測ったところ 137〜152秒が静かなブレイクで、
**153秒から最後のサビ**が入る。ここから使うと音が入ってくるところから
始まって最後まで密度が保てるので、`MUSIC_START=153` を既定にしている。
188秒あたりでまた静かになるので、全体の尺が 35 秒を超えるなら開始位置を
選び直すこと。

曲を主役にして、包丁や貝の音はその上に効かせる。バランスは定数で決まる:

```python
MUSIC_LUFS = -18.0    # 曲
CLIP_LUFS = -22.0     # 包丁・貝の音（曲の 4dB 下）
```

包丁の音をもっと立たせたいなら `CLIP_LUFS` を -20 くらいまで上げる。

### 環境音版

厨房の環境音をそのまま使い、静止画パートで無音にならないよう IMG_1749 の
環境音を薄く（-20dB 相当）全編に敷いている。

### 書き出しの音量

**`loudnorm` は測定にだけ使い、書き出しには一切通していない。** 通すと二度
痛い目を見た:

- 狙いに寄らないと動的モードへ落ちて音が暴れる（環境音版で真ピークが +6dBFS）
- 先読み 3 秒ぶん末尾が落ちる（音楽版の音声が 31.7 秒のはずが 28.8 秒になり、
  フェードアウトごと消えた）

代わりに、クリップ・音楽・全体をそれぞれ一度測り、静的ゲインで揃えてから
混ぜている。はみ出す瞬間だけ `alimiter` で止める。両方とも -16 LUFS 前後。

### 終わり方

音楽は締めのカードから引きはじめて、ロゴを越えて最後の黒で鳴り終わる
（`AUDIO_TAIL = 4.5` 秒、`AUDIO_CURVE = "qsin"`）。直線のフェードだと
終わり際が急に感じるので四分の一サインにしてある。

### 合成 BGM（予備）

`make_bgm.py` は琴ふうの撥弦・太鼓ふうのキック・パッドを合成する。
音源が用意できないときの予備。使うなら `MUSIC=reel/out/bgm.wav MUSIC_START=0`。

```bash
python3 reel/make_bgm.py 27.8      # -> out/bgm.wav
```

### アプリ側で音楽を乗せる場合

`sushi_reel_muted.mp4` を使う。Instagram はアプリ内の音源を使ったほうが
リーチ面で有利なので、リールに出すならこちらという選択肢もある。

## カバー画像

`out/cover.jpg`。リールの投稿画面で「カバーを編集」→ カメラロールから選ぶ。

Instagram はプロフィールのグリッドでカバーの**中央 1:1 だけ**を切り出すので、
1080×1920 なら y=420〜1500 に収まっているものしか一覧では見えない。
写真も文言もこの範囲に置いてある（`GRID_TOP` / `GRID_BOTTOM`）。

文言は動画の締めカードと同じ `FAIR_LEAD` / `FAIR_TITLE` / `FAIR_DATES` を使うので、
日程を差し替えればカバーも一緒に変わる。カバーだけ作り直すなら:

```bash
python3 reel/build_reel.py --cover-only
```

## 告知の段階

締めのカードは既定で「近日開催／詳しくはプロフィールから」。企画書にある
とおり販促は提供可能数が決まってから設計するので、日程が固まるまでは
日付を出さずに回せるようにしてある。決まったら `FAIR_DATES` に日付を入れ、
`FAIR_NOTE=""` で誘導行を落とす。

## 投稿文

`caption.md`。動画・カバーと同じトーンで揃えてある。日程を差し替えるときは
`FAIR_DATES` と一緒に直す。

## 素材の不足

企画書の看板は**花咲蟹**と**いくらのこぼれ軍艦**だが、どちらの画もない。
「蟹とお寿司の秋祭り」の告知としては、この2つが撮れると強さが変わる。
