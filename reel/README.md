# 寿司・魚介リール動画

スマホで撮った仕込みの素材から、Instagram リール / TikTok / YouTube ショート用の
縦動画（1080×1920 / 30fps / 約22秒）を組み立てるビルドスクリプト。

## 出力

| ファイル | 中身 |
|---|---|
| `out/sushi_reel.mp4` | 完成版。厨房の環境音（包丁・貝を開ける音）入り |
| `out/sushi_reel_muted.mp4` | 無音版。アプリ側で音楽を乗せたいとき用 |

無音版と filtergraph は生成物なのでコミットしていない。`build_reel.py` を流せば出る。

## 使い方

```bash
# ffmpeg 6.x と日本語フォント
apt-get install -y ffmpeg fonts-noto-cjk

# 素材を置いたディレクトリを SRC で渡す
SRC=/path/to/素材 python3 reel/build_reel.py

# 店名を入れる（ラストにクレジットが出る）
SRC=/path/to/素材 SHOP="鮨 ○○" python3 reel/build_reel.py

# CTA の文言を変える
SRC=/path/to/素材 CTA="DMでご予約どうぞ" python3 reel/build_reel.py
```

素材のファイル名は `build_reel.py` の `SOURCES` で指定している。

## テロップ・カットの調整

`build_reel.py` 冒頭の `SEGMENTS` を触ればいい。

```python
dict(key="tai_v", kind="video", start=9.60, dur=2.80, zoom=1.18, focus=(0.42, 0.58),
     lines=[("まずは 真鯛、一本もの。", 64, INK)]),
```

- `start` / `dur` … 元動画のどこを何秒使うか
- `zoom` / `focus` … 構図の寄せ。`focus` は `(横, 縦)` で 0.0=左/上、0.5=中央、1.0=右/下
- `lines` … `(文字列, フォントサイズ, 色)` を下から積む
- 静止画は `zoom=(開始倍率, 終了倍率)` でゆっくり寄る／引く。`fit="blur"`
  を付けると写真を切らずに全部見せて、余白を同じ写真のぼかしで埋める

テロップの位置は `CAPTION_BOTTOM`（Instagram の UI に被らない高さ）で決まる。

## 素材について

- `.mov` は iPhone の回転メタデータ付き。ffmpeg が自動で縦に起こすので触らない
- `.jpg` は EXIF Orientation=6。これも ffmpeg が自動適用するので、
  `transpose` を足すと二重回転になって上下逆さまになる
- 元素材（合計 48MB）はリポジトリに入れていない

## 音

厨房の環境音をそのまま使い、静止画パートで無音にならないよう IMG_1749 の
環境音を薄く（-20dB 相当）全編に敷いている。仕上げに `loudnorm` で
-16 LUFS / トゥルーピーク -1.5dB に寄せてある。

アプリ側で音楽を乗せる場合は `sushi_reel_muted.mp4` のほうを使う。
