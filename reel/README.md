# 寿司・魚介リール動画

スマホで撮った仕込みの素材から、Instagram リール / TikTok / YouTube ショート用の
縦動画（1080×1920 / 30fps / 約27秒）を組み立てるビルドスクリプト。

## 出力

| ファイル | 中身 |
|---|---|
| `out/sushi_reel.mp4` | 環境音のみ。包丁・貝を開ける音がそのまま入る |
| `out/sushi_reel_bgm.mp4` | 環境音 + オリジナル BGM |
| `out/sushi_reel_muted.mp4` | 無音版。アプリ側で音楽を乗せたいとき用 |

映像は 1 回だけエンコードして、音声だけ差し替えて 3 本に muxing している。
テロップやカットを触っていないときは `--audio-only` を付ければ映像を作り直さない。

コミットしているのは `sushi_reel.mp4` だけ。ほかは `build_reel.py` を流せば出る。

## 構成

仕入れ → 仕込み → 出来上がり → CTA → ロゴ の順。全 12 カット、27.2 秒。

| # | 尺 | 素材 | テロップ |
|---|---|---|---|
| 1 | 2.4s | 写真：サーモントラウトを抱える | 今日、こんなん入りました。 |
| 2 | 2.2s | 写真：ブリ + サクラマス2本 | 魚は その日のぶんだけ。 |
| 3 | 2.0s | IMG_1744 盛り籠のパン | 貝も いいのが入ってます。 |
| 4 | 2.6s | IMG_1749 真鯛の全身 | 真鯛は 一本もの。 |
| 5 | 2.0s | IMG_1749 鱗引きの寄り | 一尾ずつ、手で。 |
| 6 | 2.2s | IMG_1747 貝に包丁を入れる | 貝は、目の前で開ける。 |
| 7 | 2.4s | IMG_1747 開いた身（山場） | 開けたてが、いちばん旨い。 |
| 8 | 1.6s | IMG_1744 ホタテ・つぶ貝の寄り | ぜんぶ 今日のネタです。 |
| 9 | 2.8s | 写真：海鮮丼 | その日入荷した、旬の魚介で。 |
| 10 | 2.4s | 写真：うに軍艦 | 今日の一貫、どうぞ。 |
| 11 | 2.6s | 写真：引き＋ぼかし背景 | 貴方様を おまちしております |

ロゴのカットは `plain=True` を付けてあり、色調整もテロップも足さずに素材のまま出す。
頭 0.3 秒フェードイン、尻はロゴ側にフェードがあるので 0.2 秒だけ。

## 使い方

```bash
# ffmpeg 6.x と日本語フォント
apt-get install -y ffmpeg fonts-noto-cjk

# 素材を置いたディレクトリを SRC で渡す
SRC=/path/to/素材 python3 reel/build_reel.py

# 店名を入れる（ラストにクレジットが出る）
SRC=/path/to/素材 SHOP="鮨 ○○" python3 reel/build_reel.py

# CTA の文言を変える
SRC=/path/to/素材 CTA="DMでご予約どうぞ" python3 reel/build_reel.py
```

素材のファイル名は `build_reel.py` の `SOURCES` で指定している。

## テロップ・カットの調整

`build_reel.py` 冒頭の `SEGMENTS` を触ればいい。

```python
dict(key="tai_v", kind="video", start=9.60, dur=2.80, zoom=1.18, focus=(0.42, 0.58),
     lines=[("まずは 真鯛、一本もの。", 64, INK)]),
```

- `start` / `dur` … 元動画のどこを何秒使うか
- `zoom` / `focus` … 構図の寄せ。`focus` は `(横, 縦)` で 0.0=左/上、0.5=中央、1.0=右/下
- `lines` … `(文字列, フォントサイズ, 色)` を下から積む
- 静止画は `zoom=(開始倍率, 終了倍率)` でゆっくり寄る／引く。`fit="blur"`
  を付けると写真を切らずに全部見せて、余白を同じ写真のぼかしで埋める

テロップの位置は `CAPTION_BOTTOM`（Instagram の UI に被らない高さ）で決まる。

## 素材について

- `.mov` は iPhone の回転メタデータ付き。ffmpeg が自動で縦に起こすので触らない
- `.jpg` は EXIF Orientation=6。これも ffmpeg が自動適用するので、
  `transpose` を足すと二重回転になって上下逆さまになる
- 元素材（合計 48MB）はリポジトリに入れていない

## 音

### 環境音版

厨房の環境音をそのまま使い、静止画パートで無音にならないよう IMG_1749 の
環境音を薄く（-20dB 相当）全編に敷いている。

### BGM 版

`make_bgm.py` がその場で合成する。既成曲だと権利の確認が要るので、
琴ふうの撥弦（Karplus-Strong）・太鼓ふうのキック・パッドを組んだ完全な
オリジナル。84BPM、A マイナーペンタトニック、Am - F - C - G - Am の 10 小節。

```bash
python3 reel/make_bgm.py 27.2      # -> out/bgm.wav
```

包丁や貝の音を消したくないので、クリップ側を -18 LUFS、BGM を -23.5 LUFS に
そろえてから混ぜている（`CLIP_LUFS` / `BGM_LUFS`）。BGM を下げたいならここ。

### 書き出しの音量

一度流して測り、その値から静的ゲインを決めて、はみ出す瞬間だけリミッターで
止めている。`loudnorm` を書き出しにそのまま使うと、狙いに寄らなかったときに
動的モードへ落ちて音が暴れる（実際に環境音版で真ピークが +6dBFS まで振れた）。

両方とも -16 LUFS / 真ピーク -1.1dBFS に収まっている。

### アプリ側で音楽を乗せる場合

`sushi_reel_muted.mp4` を使う。Instagram はアプリ内の音源を使ったほうが
リーチ面で有利なので、リールに出すならこちらが基本。BGM 版は自社サイトや
LINE、YouTube など、アプリ内音源が使えないところ向け。
