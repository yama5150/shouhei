# シェフズシグネチャーのリール（デモ）

店の POP 3 枚（鮭唐揚げの地三鮮／道産豚肉の紹興酒と柑橘芳のトンポーロー／
アボカドガーリックシュリンプ）から作った 12.0 秒の試作。構成ファイルは
`configs/chef_demo.json`。

```bash
python3 .claude/skills/susudepa-reel/scripts/build_reel.py reel/configs/chef_demo.json
```

## POP の切り方

POP は下のほうに**シェフの顔写真**と**「シェフからの一言」の空欄**がある。
空欄のまま動画に出すと未完成に見えるので、上だけを切って使っている。

| 元 | 切り出し | 残るもの |
|---|---|---|
| `pop_yamaguchi.png` 1122×1402 | 上から 900px | 見出し・料理名・料理・説明文 |
| `pop_kagami.png` 1199×1312 | 上から 985px | 同上 |
| `pop_maeda.png` 1199×1312 | 上から 985px | 同上 |

横長になるので `fit: "blur"` で全幅のまま見せて、上下を同じ絵のぼかしで埋める。
POP 自体に見出しも料理名も入っているので、テロップは足していない。

## デモ止まりの理由

- **絵が止まっている。** POP の静止画 3 枚なので動きが無い。実際の皿の動画
  （湯気、箸上げ、盛り付け）が 1 皿 3 秒ずつあれば、POP を見出しに使って
  実写につなぐ形にできる
- **「シェフからの一言」が空欄。** POP が完成したら、一言をテロップに使える
- **料理の絵が実物の写真かどうか**を確認していない。イメージ画像なら、
  実物と違って見えないかを先に見たほうがいい
- **いつから出すのか**を聞いていないので、締めカードに日付を入れていない
