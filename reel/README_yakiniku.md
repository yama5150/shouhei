# 焼肉コーナー リニューアルのリール

バイキングの焼肉コーナーが新しくなった告知用の縦動画
（1080×1920 / 30fps / 14.7秒）。

## 出力

| ファイル | 中身 |
|---|---|
| `out/yakiniku_reel.mp4` | 本番用。BGM 入り |
| `out/yakiniku_reel_muted.mp4` | 無音版。アプリ側で曲を乗せたいとき用 |

## 音

元のクリップに入っている音は -36 LUFS のノイズフロアだけで、使える音が
入っていない。混ぜると 14dB 持ち上げてヒスを足すだけなので、**音楽版は
曲だけ**で作っている（`USE_CLIP_AUDIO = False`）。

曲は 4 分 25 秒ある。レベルを 1 秒ごとに測ったところ 60 秒に区切りがあり、
**61 秒から次のセクション**。そこから 74 秒へ向けて曲がいちばん盛り上がるので、
15 秒だと「入って上がっていく」形になる。`MUSIC_START=61` が既定。
一定の強さで通したいなら `MUSIC_START=155`（150〜154 のブレイク明け）。

終わりは告知カードから引きはじめて、ロゴを越えて最後の黒で鳴り終わる
（`AUDIO_TAIL = 3.5` 秒）。15 秒と短いのでカーブは直線（`tri`）にしてある。
長い動画なら `qsin` のほうが終わり際が自然。

```bash
MUSIC=/path/to/別の曲.mp3 MUSIC_START=30 python3 reel/build_yakiniku.py
MUSIC= python3 reel/build_yakiniku.py          # 無音だけにする
```

## 構成

全 8 カット、14.7 秒。

| # | 尺 | 素材 | テロップ |
|---|---|---|---|
| 1 | 2.0s | IMG_1959 焼き野菜の盛り合わせ | 焼肉コーナー、／リニューアル。 |
| 2 | 1.5s | IMG_1959 野菜の皿 | 焼き野菜も、充実。 |
| 3 | 2.2s | IMG_1959 肉のトレーの棚 | 焼き鶏は 取り放題。 |
| 4 | 2.2s | 写真 サラダ・前菜コーナー | ほかのコーナーも、どうぞ。 |
| 5 | 1.7s | IMG_1959 ハロウィンのかぼちゃ | 秋のバイキング、開催中。 |
| 6 | 2.6s | 告知カード（写真をぼかした暗い地） | バイキング 焼肉コーナー／リニューアル／詳しくはプロフィールから |
| 7 | 2.0s | 店のロゴテンプレ | — |
| 8 | 0.5s | 黒 | — |

いちばん色のある焼き野菜を頭に置いて、肉 → 他のコーナー → 季節感、の順。
頭にフェードインは入れていない（`FADE_IN = 0`）。入れると 1 フレーム目が
黒くなり、ポスター画像に拾われたときに黒い絵が出る。

## 文言を変える

```bash
CARD_LEAD="10/31まで" python3 reel/build_yakiniku.py
CARD_NOTE="" python3 reel/build_yakiniku.py        # 誘導行を消す
```

テロップそのものは `SEGMENTS` の `lines` を直す。

## 素材について

- `.mov` は iPhone の回転メタデータ付き。ffmpeg が自動で縦に起こすので触らない
- `.jpg` の EXIF 回転も ffmpeg が自動で当てる。`transpose` を足すと二重回転になる
- 元素材はリポジトリに入れていない。`SRC` で渡す
- 棚に写っている「LUMB BBQ」のサインはテロップでは触れていない。
  読み取りに自信が持てないため

## 書き出しの音量

`loudnorm` は測定にだけ使い、書き出しには通していない。通すと動的モードに
落ちて音が暴れるうえ、先読み 3 秒ぶん末尾が落ちることがある。測ってから
静的ゲインで揃え、はみ出す瞬間だけ `alimiter` で止める。
