# マグロ一本の告知リール

「毎週月曜・金曜、マグロをまるまる捌きます」の告知。13.3 秒。
構成ファイルは `configs/maguro.json`。

```bash
TITLE_L1="毎週 月曜・金曜" TITLE_L2="マグロ一本" TITLE_EMOJI="🐟🔪✨" \
  /usr/bin/python3 .claude/skills/susudepa-reel/scripts/make_title.py --out reel/out
mv -f reel/out/title.png reel/out/maguro_title.png

python3 .claude/skills/susudepa-reel/scripts/build_reel.py reel/configs/maguro.json
```

## 素材

| ファイル | 中身 |
|---|---|
| `maguro.mov` | マグロ一本の流し撮り（512×910・31.0秒・平均輝度 125） |
| `still_maguro.png` | 上の 0.90 秒（締めカードの地） |
| `still_maguro2.png` | 上の 9.60 秒（サムネの地） |
| `logo_sting.mp4` | 店のロゴテンプレ |
| `bgm2.mp3` | BGM |

**テロップの焼き込みは無い。** 9月の動画と違って全編そのまま使える。輝度も
122〜130 で揃っているので `lift` は要らなかった。音は -33.1 LUFS、ほぼ無音
なので混ぜていない（`use_clip_audio: false`）。

元は頭から尾へ一度流して、最後にまた頭へ戻る 1 本のパン。同じ絵が続くので、
寄り（`zoom`）を変えてカットの差を作っている。解像度が 512×910 しかないので
寄せるのは 1.10 までに留めた。

## 構成（13.3 秒）

| # | 尺 | 素材の位置 | テロップ |
|---|---|---|---|
| 0 | 1.60s | 0.30 頭の寄り（目と札） | マグロ、一本まるごと。 |
| 1 | 1.50s | 9.00 頭＋胴（zoom 1.10） | —（一拍おく） |
| 2 | 1.80s | 16.50 全身 | 頭から、尾まで。 |
| 3 | 1.70s | 21.50 尾のほう（zoom 1.08） | 丸のまま、入ります。 |
| 4 | 1.40s | 29.20 頭に戻る（zoom 1.06） | — |
| 5 | 2.80s | 締めカード | ススデパの 寿司コーナー／毎週 月曜・金曜／マグロを一本、捌きます |
| 6 | 2.00s | ロゴ | — |
| 7 | 0.50s | 黒 | — |

締めカードの `lift` は **0.58**。地の写真が発泡スチロールで明るく、既定のまま
だと輝度 77 の灰色いカードになってロゴの黒へのつながりが切れた。ガンマを
下げて 31 まで落としてある（ロゴが 45、黒が 43）。

## 音

`bgm2.mp3` の **174秒から**（174〜187秒が安定して密度が高い区間）。
書き出しは -16.4 LUFS / 真ピーク -5.4 dBFS。

## 裏取りが要るもの

- **札の「33.2」。** はっきり映っているが、kg かどうかこちらで確認できないので
  文字では触れていない。確定なら「この日は 33.2キロ。」を 1 カット目に足せる。
  数字は強いので、出せるなら出したほうがいい
- **「寿司コーナー」。** どこで出すかは聞いていないので、企画書に寿司台がある
  ことから書いた。違うなら締めカードと投稿文の両方を直す
- マグロの種類（本マグロ／メバチなど）は映像から判断できないので書いていない

## 無い素材

**捌いている画が無い。** いまの素材は箱に入った一本だけなので、「これを捌きます」
の予告にはなるが、実際に捌くところは見せられていない。包丁が入る瞬間と、
切り出したサクかブロックが撮れると、2 カット足すだけで強さが変わる。
