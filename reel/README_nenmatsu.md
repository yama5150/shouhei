`configs/nenmatsu_demo.json`、ビルダーは `.claude/skills/susudepa-reel/`。

python3 .claude/skills/susudepa-reel/scripts/build_reel.py reel/configs/nenmatsu_demo.json

## 素材について（重要）

**使える素材は「ススデパ9月」の完成動画 1 本だけ。** 年末年始の絵はまだ無い。

| | |
|---|---|
| 解像度 | 512×910。出力の 1080×1920 に対して 2.1 倍の拡大になる |
| 尺 | 45.1 秒 |
| テロップ | 焼き込み済み。ほぼ全編に乗っている |

テロップが乗っていない区間はこの 4 つしかなく、合計 9.5 秒。デモはここだけで
組んである。

| 区間 | 中身 |
|---|---|
| 3.0〜5.4 | ワゴンが席へ来る（引き） |
| 12.1〜15.0 | 目の前で握る → ワゴンの寄り |
| 21.5〜23.8 | 炙り肉寿司を席に出す |
| 35.5〜37.4 | 出汁巻きを運んで席に置く |

テロップを避けて切り抜くのは無理だった。文字が画面の中央（高さの 0.4〜0.6）に
入っているので、外そうとすると幅 210px ほどしか残らず、拡大率が 5 倍を超える。

`src` は素材を置いたディレクトリ。セッションごとに変わるので、組み直すときは
構成ファイルの `src` を書き替える。必要なのは次の 4 つ。

```
susudepa_9gatsu.mov    もらった 9 月の完成動画
still_nigiri.png       上の 12.90 秒を静止画で抜いたもの（サムネの地）
still_serve.png        上の 23.40 秒を静止画で抜いたもの（締めカードの地）
logo_sting.mp4         店のロゴテンプレ（720×1280・2秒）
bgm.mp3                仮の BGM
```

## 構成（13.3 秒）

| # | 尺 | 素材の位置 | テロップ |
|---|---|---|---|
| 0 | 1.35s | 12.15 握る | 目の前で、握ります。 |
| 1 | 1.60s | 3.10 ワゴンが来る | ワゴンが、お席まで。 |
| 2 | 1.30s | 13.70 ワゴンの寄り | —（一拍おく） |
| 3 | 2.10s | 21.60 席に出す | 炙り肉寿司、一貫ずつ。 |
| 4 | 1.80s | 35.55 出汁巻きを運ぶ | 出汁巻きも、ワゴンで。 |
| 5 | 2.60s | 締めカード | お席まで、運びます／北海道グルメフェア／11月2日スタート |
| 6 | 2.00s | ロゴ | — |
| 7 | 0.50s | 黒 | — |

掴みを「握る」にしてあるのは、ワゴンの引きの絵が暗くて 1 フレーム目が弱いため。

## 色

素材の平均輝度が 107/255 と沈んでいる。席に出すカットと出汁巻きのカットが
特に暗く（78・80）、`lift` を 1.52 / 1.58 まで上げて 98〜134 に持ち上げた。
これ以上上げると黒が浮くので止めてある。

## 音

仮の BGM（`bgm.mp3`、265秒）の **155秒から**。150〜154秒が落ちたあとの
セクション頭なので、音が入ってくるところから始まる。クリップの音は元動画の
BGM が焼き込まれているので混ぜていない（`use_clip_audio: false`）。

書き出しは -17.2 LUFS / 真ピーク -2.3 dBFS。
