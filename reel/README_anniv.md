「ススキノデパート グルメフェア総集編」＋「12月4日〜6日 2周年記念イベント」。
19.2 秒。構成ファイルは `configs/anniv.json`。

```bash

python3 .claude/skills/susudepa-reel/scripts/build_reel.py reel/configs/anniv.json
```

これまでに集まった素材を全部混ぜた総集編。使っているのは
`maguro.mov` / `susudepa_9gatsu.mov` / `sengyo.jpg` / `buffet.jpg` /
`kaki.jpg` / `kuma.jpg` / `logo_sting.mp4` / `bgm2.mp3`。

## 「スタイリッシュ」の作り方

ほかの 2 本と同じ素材・同じビルダーだが、次の 4 つを変えてある。

| | ほかの版 | この版 |
|---|---|---|
| テロップの数 | 1 カットに 1 つ | **本編で 3 つだけ** |
| 文字サイズ | 60〜62px | 56px |
| 下地（`chip`） | `@0.60` | `@0.42` |
| 尻のフェード | `tri` 3.0〜3.2秒 | `qsin` 3.5秒 |

**文字を減らすのがいちばん効く。** 11 カットのうち 8 カットは無文字で、絵だけ
で流れを作っている。説明しないぶん、1 枚ずつの絵が立つ。

掴みはマグロの全身。黒くて縦に長いので、縦画面の 1 枚目として強い。
2 カット目で鮮魚に引き継いで「北海道」を言い、そのあとは店の中の流れに移る。

サムネだけは**焼き柿の皿**にしてある。鮮魚の桶盛りは年末年始版、マグロの頭は
マグロ版で使っているので、プロフィールのグリッドで並んだときに 3 本が別の絵に
なるようにした。

## 曜日

12月4日は金、5日は土、6日は日（2026年）。カレンダーで確認済み。

## 音

`bgm2.mp3` の **89秒から**（89〜109秒、幅 1.2dB といちばん揺れが小さい区間）。
ほかの 2 本は 172〜174秒から使っているので、3 本並べても同じ場所にならない。
尻は `qsin` で 3.5 秒かけて引く。

書き出しは -16.4 LUFS / 真ピーク -6.6 dBFS。

## 裏取りが要るもの

- **12月4日〜6日の日程**（企画書どおり。6日が2周年記念日）
- 投稿文に書いた**和牛の切り出しとシャンパンのサービス**は企画書の予定。
  確定していないなら落とす

企画書で確認中だったもの（毛ガニの数量限定表記・エゾ鹿の産地表記・数の子・
小樽の地鶏）は映像にも投稿文にも出していない。社内の情報も入れていない。
