## Cyber Rose Crimson

ビジュアルノベル。全16話・単一HTML(素材はbase64で内包)。

- 本体は `crc/index.html` の**1ファイルのみ**。名前を変えないこと(URLが変わる)
- 更新するときは `crc/index.html` を丸ごと差し替えて push
- `crc/_headers` は Netlify 配信時のキャッシュ制御用(GitHub Pages では無視される)
